    AI Cost Governance Gateway

    A management portal and governance API with Azure API Management as the AI and MCP gateway. Inference requests are admitted only when a conservative maximum charge fits the team's remaining budget, and token metrics are emitted by team, model, and caller for chargeback.

    • Budget is reserved before a model call is sent
    • Token metrics by team, model and caller for chargeback
    • Agents and service principals spend their team's budget

About

I'm a Solution Engineer at Microsoft focused on Cloud & AI, based in Texas. Most of my work sits where generative AI meets enterprise reality: identity, governance, cost control, observability, and getting from a demo to something a platform team can own.

The areas I spend the most time in are Azure AI Foundry and agents, AI gateways with Azure API Management, retrieval-augmented generation and document AI, real-time voice AI, and data platforms with Microsoft Fabric.

Everything listed here is a personal reference project published to GitHub. Fork it, adapt it, and open an issue if something is unclear.
